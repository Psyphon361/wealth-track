# Wealth Tracker (prototype v1)

Personal wealth tracking for FD, RD, stocks, bonds, and mutual funds.

## Layout

- `api/` - FastAPI backend
- `web/` - Next.js frontend
- `docs/PLAN.md` - project plan

## Stack

- Next.js + shadcn (web)
- FastAPI (api)
- Neon Postgres (database)
- npm (web package manager)
